    16 · Representation

    Turning raw tokens into vectors: counting, predicting and contrasting.

    Before a model can learn, its input must be a vector — and how you build that vector often matters more than the model. Sparse counting, distributional embeddings, tokenizers, contrastive objectives and ANN indexes all live here.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
