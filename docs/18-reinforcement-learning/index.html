    18 · Reinforcement learning

    Learning from consequences: values, policies, models and preferences.

    RL is the study of sequential decisions under delayed reward. This folder builds the Bellman machinery first, then the deep algorithms, then the alignment-flavoured ones (offline RL, reward models, DPO) that dominate current practice.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
