    19 · Tabular frontier

    The current state of the art on the most common data type in industry.

    Tabular learning had a quiet revolution: prior-fitted networks, recursive feature machines and parameter-efficient MLP ensembles now rival tuned gradient boosting. These are the papers worth knowing from the last three years.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
