    10 · Sequences

    Order matters: Markov structure, alignments, recurrences and state-space models.

    Everything that reads left to right lives here: the classical probabilistic machinery (Markov chains, HMMs, CRFs, CTC), the distance notion for time series (DTW) and the neural sequence blocks (RNN, TCN, attention, SSMs).

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
