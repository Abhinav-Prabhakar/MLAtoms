    04 · Trees & ensembles

    Recursive partitioning and the boosting/bagging machines that still win tabular benchmarks.

    Gradient-boosted trees remain the default answer for tabular data. This folder builds the tree from scratch, then the four boosters worth knowing, then the ensembling meta-algorithms that generalise all of it.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
