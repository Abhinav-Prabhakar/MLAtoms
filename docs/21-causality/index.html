    21 · Causality

    From correlation to intervention: identification, estimation and discovery.

    Prediction is not explanation. This folder is the toolkit for answering 'what happens if we act?' — potential outcomes and estimators first, then the discovery algorithms that recover structure from observational data.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
