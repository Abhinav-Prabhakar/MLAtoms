    11 · Time series

    Forecasting atoms: from exponential smoothing to patch transformers.

    Forecasting is a separate discipline because the data breaks i.i.d. assumptions. This folder spans the classical state-space methods, the decomposition toolbox, and the modern neural forecasters — each with the baseline it must beat.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
