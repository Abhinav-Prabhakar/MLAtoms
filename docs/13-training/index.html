    13 · Training

    The craft: how models are actually fitted, compressed and adapted.

    Between a model definition and a working product sits training. These files are the procedures rather than the models: autodiff, distillation, adapters, pruning, quantisation, active learning, imbalance handling.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
