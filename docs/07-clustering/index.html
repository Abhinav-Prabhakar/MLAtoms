    07 · Clustering

    Grouping without labels: centroid, density, graph, hierarchy and mixtures.

    Clustering has no single objective, which is why there are a dozen algorithms and no winner. Each file here states the objective it optimises so you can pick the one that matches your notion of a cluster.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
