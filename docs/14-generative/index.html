    14 · Generative models

    Models that produce data: latent, adversarial, flow and diffusion.

    Four families, one question: how do you represent and sample a distribution? Latent-variable models give you a decoder, GANs give you sharpness, flows give you exact likelihood, diffusion gives you both quality and control.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
