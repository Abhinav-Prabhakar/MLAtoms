    20 · Evaluation & uncertainty

    Knowing whether you are right — and how much you do not know.

    A model is only as good as the evidence behind it. This folder covers honest resampling, calibrated probabilities, conformal guarantees, drift monitoring and the statistical tests that stop you shipping noise.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
