    08 · Manifolds & embeddings

    Trust the manifold: nonlinear embeddings for visualisation, structure and features.

    Real data lies near a low-dimensional surface. These methods recover it — for plots (t-SNE, UMAP), for distances (Isomap, diffusion maps) or for features (autoencoders, random projections).

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
