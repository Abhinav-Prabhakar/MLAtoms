    09 · Density & anomaly

    How likely is this point? Density estimation and the detectors built on it.

    Anomaly detection is density estimation with a threshold. This folder gives you the estimators (KDE, copulas, extreme-value tails) and the practical scorers (LOF, isolation forest, Mahalanobis, reconstruction error) that industry actually deploys.

    How to read an atom #

    Each atom is two files with the same stem: name.py is the implementation, name.md is the companion document (intuition, derivation, variant map, complexity, failure modes, applications). Start with the .md.

    See docs/conventions.md for the file contract and docs/tiers.md for what the tier column means.
